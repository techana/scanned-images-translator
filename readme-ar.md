# مترجم الصفحات الممسوحة ضوئيًا

ترجمة صفحات المستندات الممسوحة ضوئيًا (أدلة الاستخدام، الكتيّبات، أوراق
المواصفات) **مباشرة على الصورة نفسها** — مثل وضع الكاميرا في ترجمة Google،
لكنه قابل للبرمجة، وبالدقة الكاملة، وقابل للتحرير، ويعمل دون اتصال بالإنترنت
على أجهزة Mac.

يتعرف البرنامج على نصوص كل صفحة، ويجمعها في كتل بصرية، ويترجمها، ثم يعيد
رسم الترجمة فوق الصورة الأصلية — مع الحفاظ على تخطيط الصفحة والجداول
والأيقونات والشعارات والرسومات.

## المزايا

- **التعرف الضوئي عبر Vision في macOS** مع إحداثيات على مستوى الحرف؛
  أكثر من ٣٠ لغة (اليابانية، الصينية، الكورية، العربية، ومعظم اللغات الأوروبية…)
- **ثلاثة محركات ترجمة** تُجرَّب بالترتيب:
  ١. **إطار Apple للترجمة** — دون اتصال، مجاني، خصوصية كاملة (macOS 15+)
  ٢. **Google Cloud Translation v3** — يتطلب مشروع GCP مع تفعيل الفوترة
  ٣. نقطة نهاية Google المجانية — حل أخير بلا مفاتيح
- **أي زوج لغات**، بما في ذلك اللغات المكتوبة من اليمين إلى اليسار
  (العربية، العبرية، الفارسية، الأردية) مع تشكيل صحيح للحروف ومحاذاة يمينية
  وخطوط مناسبة
- **محرر مرئي في المتصفح** (`gui.py`) بمبدأ "ما تراه هو ما تحصل عليه":
  - تصفح الصفحات مع شريط تحكم بشفافية طبقة الترجمة
  - تحريك وتحجيم وتحرير وإنشاء وحذف كتل النصوص؛ تراجع (⌘Z)
  - حجم الخط، تباعد الأسطر، لون الخط، الخلفية (أبيض / لون يُلتقط من
    الصورة بالقطّارة / شفاف)
  - شارات حمراء على الكتل التي يتجاوز نصها حدود مربعها
  - الصور المحفوظة مطابقة تمامًا لما يعرضه المحرر
- **سطر أوامر للمعالجة الدفعية** (`translate_pages.py`) مع ذاكرة تخزين لكل
  صفحة — إعادة الرسم فورية؛ يجري التعرف الضوئي والترجمة مرة واحدة فقط
- حماية الأيقونات والرموز: النقاط والأزرار والأسهم التي يخطئ التعرف الضوئي
  في قراءتها تبقى كما هي في الصورة الأصلية ولا يُرسم فوقها أبدًا

## المتطلبات

- macOS 15 أو أحدث (لترجمة Apple؛ الإصدارات الأقدم تعمل مع محركات Google)
- أدوات سطر أوامر Xcode (لبناء المساعدين المكتوبين بلغة Swift)
- Python 3 مع مكتبة [Pillow](https://python-pillow.org) مبنية مع
  **libraqm** لدعم اللغات اليمينية

## الاستخدام

### الواجهة الرسومية

<div dir="ltr">

```bash
python3 gui.py
```

</div>

تفتح على `http://localhost:8877`. استخدم قائمة **Files ▾** لفتح صورة أو
مجلد صفحات، وحرّر الكتل كما تشاء، ثم احفظ عبر **Save current page** ‏(⌘S)
أو **Save current as…** أو **Save all pages**. عند الحفظ الأول تختار صيغة
الإخراج — PNG، أو PNG محسَّن (لوحة ألوان الويب مع تشويش نمطي، أصغر بنحو
٦ مرات)، أو PNG-8 متكيّف (٢٥٦ لونًا)، أو PNG-8 رمادي، أو PNG أحادي البت،
أو JPEG بجودة ٦٠/٣٠/١٠٪ — ومكان الحفظ؛ وتُعاد تلقائيًا في مرات
الحفظ التالية. الناتج: `<page>_<lang>.png|.jpg` بدقة المصدر الكاملة. ومن **Files ▾ ← Settings…**
تختار لغة التعرف الضوئي واللغة الهدف ومحرك الترجمة (مع تنزيل حزمة لغات
Apple لمرة واحدة عند الحاجة).

### سطر الأوامر

<div dir="ltr">

```bash
# ترجمة مجلد صفحات (يكتب <page>_<lang>.png بجوار المدخلات)
python3 translate_pages.py scans/

# اختيار اللغات والمحرك
python3 translate_pages.py --source ja-JP --target ar --engine apple scans/

# مع واجهة Google الرسمية وتصحيحات تعرف ضوئي خاصة بالمستند
python3 translate_pages.py --project <gcp-project> --fixes fixes-carmarty.json scans/
```

</div>

الأمران `./ocr --list-langs` و`./translate --list-langs` يعرضان اللغات
المدعومة للتعرف الضوئي والترجمة.

## ملاحظات

- نتائج التعرف الضوئي والترجمة تُخزَّن في `<outdir>/.cache/<page>.json`؛
  احذف ملف الصفحة (أو مرّر `--force`) لإعادة معالجتها. تعديلاتك اليدوية في
  المحرر تُحفَظ في الذاكرة نفسها.
- صيغ المدخلات: `.jp2 .png .jpg .jpeg .tif .tiff .bmp`.
- يعمل على macOS فقط (Vision + ترجمة Apple). لاستبدال محرك التعرف الضوئي
  يكفي الالتزام بعقد JSON الخاص بالمساعد `ocr`.
