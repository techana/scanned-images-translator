# مترجم الصور الممسوحة ضوئيًا

[English](readme.md) · **عربي**

حوّل الصفحات الممسوحة ضوئيًا (مثل الإعلانات المطبوعة وكتلوجات الاستخدام وأوراق المواصفات)
إلى صفحات مترجمة **تحافظ على شكل الأصل تمامًا**. يقرأ البرنامج النص الأصلي
بتقنية التعرف الضوئي OCR، ويترجمه، ثم يعيد كتابة الترجمة فوق الصورة نفسها، مع بقاء
الجداول والرسوم والأيقونات والشعارات في أماكنها. ويمكنك بعد ذلك إذا أردت تعديل النتيجة
في محرر مرئي على المتصفح.

تخيّله مثل وضع الكاميرا في ترجمة Google، لكن بالدقة الكاملة، مع حرية تحرير النصوص المترجمة، والعمل دون اتصال إنترنت. يعمل على macOS و Linux و Windows.

<div dir="ltr">

![المحرر أثناء العمل على صفحة دليل ممسوحة](docs/screenshot-ar.png)

</div>

*دليل ياباني مُترجَم تلقائيًا إلى العربية — مع بقاء التخطيط والجداول
والرسوم كما هي.*

## ماذا يستطيع أن يفعل

- **قراءة أكثر من ٣٠ لغة** عبر محرك Vision في macOS، أو عبر **Tesseract**
  (يعمل على إصدارات macOS الأقدم وعلى Linux وWindows).
- **الترجمة دون اتصال انترنت** بمترجم Apple المدمج مع macOS 15 أو أحدث، أو بالاتصال بالإنترنت باستخدام ترجمة قوقل السحابية Google Cloud Translation.
- **تحرير النصوص في المتصفح**: انشئ وحرّر كتل النص وغيّر مواقعها وأحجامها وألوانها،
 مع إمكانية التقط ألوان خلفية النصوص من الصورة نفسها. 
  التطبيق يعتمد مبدأ WYSIWYG أي أن ما تراه هو ما يُحفَظ حرفيًا.
- **حفظ الصفحات كصور أو وثائق**: الصور بصيغة PNG ملونة أو رمادية أو أبيض
  وأسود، أو بصيغة JPEG — الوثائق بصيغة **PDF مع طبقة نص مخفية قابلة للبحث**.
- **معالجة كتاب كامل دفعة واحدة** من سطر الأوامر أو الواجهة الرسومية؛ كل صفحة تُخزَّن مؤقتًا.

## التثبيت

يعمل على **macOS و Linux و Windows**. تحتاج إلى Python 3، وللتعرّف الضوئي
إمّا محرك Vision في macOS (الإصدار 15 أو أحدث) أو Tesseract في غير ذلك.

<div dir="ltr">

```bash
git clone https://github.com/techana/scanned-images-translator.git
cd scanned-images-translator
pip3 install -r requirements.txt
```

</div>

ثم هيّئ التعرّف الضوئي حسب نظامك:

**macOS 15+** — محرك Vision المدمج هو الافتراضي؛ ابنِ المساعدَين بلغة
Swift مرة واحدة (يتطلب أدوات Xcode: `xcode-select --install`):

<div dir="ltr">

```bash
swiftc -O -o ocr ocr.swift
swiftc -O -o translate translate.swift
```

</div>

**Linux** — ثبّت Tesseract وبيانات لغاته والخطوط:

<div dir="ltr">

```bash
sudo apt install tesseract-ocr tesseract-ocr-jpn tesseract-ocr-ara \
                 fonts-dejavu fonts-noto zenity
```

</div>

**Windows** — ثبّت [Tesseract](https://github.com/UB-Mannheim/tesseract/wiki)
(إصدار UB-Mannheim، مع اختيار بيانات اللغات أثناء التثبيت) وتأكد من أن
`tesseract.exe` ضمن مسار PATH.

على Linux وWindows يستخدم التطبيق افتراضيًا Tesseract للتعرّف الضوئي
وGoogle للترجمة (مترجم Apple دون اتصال يعمل على macOS فقط). تُختار
اللغات والمحركات في أي وقت من **Files ▾ ← Settings…**

## الاستخدام

**على الـ Mac يكفي النقر المزدوج على `Images Translator.app`** الموجود في
هذا المجلد — دون الحاجة إلى الطرفية. سيبدأ التطبيق ويُفتح في متصفحك،
ولإيقافه اختر **Files ▾ ← Quit**.

> في المرة الأولى فقط: إن قال macOS إنه «من مطوّر غير معروف»، انقر على
> التطبيق بالزر الأيمن مرة واحدة واختر **Open** ← **Open**. (يحدث هذا فقط
> إن نزّلت المشروع كملف ZIP؛ أما `git clone` فلا يُعلَّم.)

أو شغّله من الطرفية على أي نظام:

<div dir="ltr">

```bash
python3 gui.py
```

</div>

يعمل التطبيق كخادم ويب محلي صغير ويُفتح تلقائيًا في متصفحك على العنوان
**http://localhost:8877** — وإن لم يُفتح تلقائيًا فالصق هذا العنوان في أي
متصفح. (استخدم `python3 gui.py --port 9000` إن كان المنفذ 8877 مشغولًا.)
ولا يُرفع أي شيء إلى الإنترنت؛ فالخادم يستمع على جهازك وحده.

بعدها من **Files ▾ ← Load a folder…** اختر مجلد الصفحات، وستُتَرجم كل
صفحة عند عرضها. انقر أي كتلة نص لتعديلها؛ واسحب شريط *Opacity* لرؤية
الأصل تحتها. **⌘S** يحفظ الصفحة — الحفظ الأول يسألك عن المكان والصيغة ثم
يتذكر اختيارك.

اللغات ومحرك الترجمة في **Files ▾ ← Settings…**

**سطر الأوامر** لمعالجة مجلدات كاملة:

<div dir="ltr">

```bash
python3 translate_pages.py scans/                          # ياباني ← إنجليزي
python3 translate_pages.py --source ja-JP --target ar scans/   # ← عربي
```

</div>

تُحفَظ النتائج بجوار المدخلات باسم `<page>_<language>.png`.

## جدير بالمعرفة

- **أفضل النتائج تأتي من جهاز Mac حديث.** محرك Vision في macOS (على macOS 15 فأحدث) يعتمد نماذج تعرّف عصبية من Apple مدرَّبة على صور
  وصفحات واقعية، ويتفوّق بوضوح على Tesseract في الصفحات المطبوعة بنقاط
  الظل (halftone). يستخدم Tesseract أيضًا شبكات LSTM العصبية الذكية منذ
  الإصدار 4 وهو بديل جيّد على Linux وWindows وإصدارات macOS الأقدم،
  لكن توقّع منه نتائج أسوأ للصفحات المشوّشة، أي مزيدًا من التصحيح اليدوي
  في المحرر.
- **نسخ العناصر ولصقها** بالاختصارين ⌘C و⌘V (أو Ctrl على Linux وWindows).
 اختر مربع النص أو مستطيل الرقعة وانسخ، ثم ألصق في موقع مؤشر الفأرة.
- نتائج التعرف الضوئي والترجمة تُخزَّن لكل صفحة في مجلد `images_translator.cache/`
- الأمران `./ocr --list-langs` و`./translate --list-langs` يعرضان كل
  اللغات التي يدعمها جهازك.
- أخطاء التعرف الضوئي المتكررة تحفظ في مستند معيّن وتُصحَّح مرة واحدة بملف
  تصحيحات صغير (انظر المثال `fixes-carmarty.json` ومرّره بـ `--fixes`).
